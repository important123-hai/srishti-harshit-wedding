# Tijara Fort Wedding Invite

## Files
- `index.html` — complete responsive interactive wedding invitation
- `assets/music.mp3` — add your licensed/permissioned wedding music here
- `assets/tijara-fort.jpg` — optional; the current design uses a CSS illustration, but you can replace it with a real fort image.

## What is already included
- Full-screen royal opening
- Animated fort doors
- Background lanterns
- Background music with play/pause
- Scratch-to-reveal date card (mouse + touch)
- Doctor/ECG themed couple section
- Haldi / Mehendi / Sangeet / Wedding timeline
- Responsive mobile/tablet/laptop layout
- RSVP and map buttons
- Scroll animations

## Replace these placeholders in index.html
Search for:
- `[WEDDING DATE]`
- `[DATE]`
- `[TIME]`
- `[LOCATION]`
- Google Maps URL
- RSVP URL

## Music
Put an MP3 named exactly:
`assets/music.mp3`

Important: browsers generally block automatic audio until the visitor interacts with the page. This invite starts music when the guest presses "Enter the Celebration".

## Deploy free
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Go to Settings → Pages.
4. Select the main branch.
5. Share the generated HTTPS link on WhatsApp.

### Netlify
Drag the whole folder to Netlify's deploy area, or connect a GitHub repository.

## Real Tijara Fort background
If you want the actual fort photo, add:
`assets/tijara-fort.jpg`
and change the relevant section's CSS background to:
`url("assets/tijara-fort.jpg") center/cover no-repeat`
Use a photo you own or have permission to use.
